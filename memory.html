How to Play

  1. Select a difficulty and the number of pairs.
  2. Click Start Game to reveal all the pictures.
  3. Memorize the pictures before they become hidden.
  4. Select two cards to find a matching pair.
  5. Continue until every pair has been matched.
  6. Enter your name to save a qualifying score.

Scoring Rules

+10 Successful match
-5 Incorrect match
-1 Per overtime second

When the timer reaches zero, the game continues in overtime until all pairs are matched.
